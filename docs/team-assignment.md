# Phân công nhóm (3 sinh viên)

## SV1 — Nông dân
- Phụ trách chính: Season Dashboard, Field Log, Help Request.
- Đồng phụ trách một phần giao diện dùng chung.
- Chịu trách nhiệm responsive + kiểm tra giao diện phần mình.

## SV2 — Chuyên gia nông nghiệp
- Phụ trách chính: Request Queue, Request Detail, Resource Library.
- Đồng phụ trách tương tác JavaScript / dữ liệu giả lập.
- Đánh giá PR của SV1 hoặc SV3.

## SV3 — Điều phối HTX + Quản trị viên
- Phụ trách chính: Farm Overview, Calendar, Season Summary, Dashboard, Crop Mgmt, User Mgmt.
- Tích hợp bố cục, điều hướng, bảng điều khiển/quản trị và phát hành.
- Đánh giá tính nhất quán toàn dự án.

## Trách nhiệm chéo bắt buộc (xuyên suốt)
Mỗi sinh viên nhận ít nhất một trách nhiệm ngang, để tránh 3 "website con" rời rạc:
- **SV1:** Hệ thống thiết kế / Điều hướng / Khả năng tiếp cận.
- **SV2:** JavaScript / Dữ liệu / Tương tác AI.
- **SV3:** Responsive / Tích hợp / Phát hành / Đảm bảo chất lượng.

## Lát cắt dọc bắt buộc
Mỗi sinh viên tự hoàn thành ≥ 1 luồng end-to-end:
```text
Mockup → HTML → CSS → JavaScript → Dữ liệu → Responsive → Nhánh Git → Commit → PR → OBS
```
Không chấp nhận: một người chỉ làm tài liệu/Figma, một người chỉ HTML, một người chỉ JavaScript.
